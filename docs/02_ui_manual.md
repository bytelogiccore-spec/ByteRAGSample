# 🖥️ CodeOrbit UI 사용자 매뉴얼 (UI Manual)

본 문서는 **CodeOrbit 데스크톱 애플리케이션의 화면 구성과 조작 방법**을 설명합니다.

---

## 1. 화면 레이아웃 구성

CodeOrbit 대시보드는 **Stitch AI 디자인 시스템(Cyber-Kinetic Developer Core)**을 기반으로 구성되어 있습니다.

```
+------------------+-------------------------------------------------------------+
| [CO] CodeOrbit   | [ D:\Target\Project... ] [타겟 적용]   [⚡즉시 재인덱싱] [트레이 숨김] |
| AST GRAPH ENGINE |                                                             |
+------------------+-------------------------------------------------------------+
| ⚡ 대시보드 개요  | [INDEXED FILES]  [KNOWLEDGE NODES]  [RELATION EDGES]  [STORAGE]  |
| 🔌 MCP 도구 상태  |       2,273             99                 184        ByteRAG 5T |
| ⚙️ 환경 설정     +-------------------------------------------------------------+
|                  | GRAPH EXPLORER & SYMBOL SEARCH                              |
|                  | [ 검색할 심볼 이름, 구조체, 함수 입력...            ] [탐색] |
|                  +-------------------------------------------------------------+
|                  | ┌─ [struct] AppState ─────────────────────────────────────┐ |
|                  | │ crates/codeorbit/src/main.rs (L15)                      │ |
|                  | └─────────────────────────────────────────────────────────┘ |
+------------------+-------------------------------------------------------------+
| ● MCP READY      |                                                             |
+------------------+-------------------------------------------------------------+
```

## 2. 주요 기능 조작 가이드

### ① 타겟 프로젝트 변경 (`상단 바`)
1. 상단 입력창에 분석하고자 하는 프로젝트의 절대 경로(예: `D:\ByteLogicCore\ByteRAGSample` 또는 다른 프로젝트 폴더)를 입력합니다.
2. **[타겟 적용]** 버튼을 누릅니다.
3. CodeOrbit이 해당 프로젝트 폴더를 즉시 스캔하여 지식 그래프를 새로 생성합니다.

### ② 실시간 4대 지표 카드 (`대시보드 개요`)
- **INDEXED FILES**: 분석 대상 폴더 내 인식된 다국어(Rust, C++, C#, TS, Py) 소스 파일 총 개수.
- **KNOWLEDGE NODES**: 추출된 심볼(구조체, 클래스, 함수, 인터페이스, 트레이트 등) 개수.
- **RELATION EDGES**: 심볼 간의 연결 관계(호출, 상속, 구현, 임포트) 간선 개수.
- **STORAGE ENGINE**: `ByteRAG 5-Tier` 영속 DB 엔진 연동 상태.

### ③ 심볼 실시간 탐색 (`Graph Explorer`)
1. 검색창에 찾고 싶은 구조체명, 함수명, 클래스명을 입력합니다 (예: `GraphStore`, `AppState`, `parse_file`).
2. **[탐색]** 버튼을 누르거나 `Enter` 키를 누릅니다.
3. 아래 목록에 해당 심볼의 **정확한 파일 위치, 라인 번호, 심볼 타입 배지**가 즉시 표시됩니다.

### ④ 시스템 트레이 상주 & 창 숨김
- **창 최소화/숨김**: 대시보드 우측 상단 **[트레이로 숨김]** 버튼을 누르거나 창 닫기(`X`) 버튼을 누르면 프로그램이 종료되지 않고 **윈도우 작업표시줄 우측 트레이로 숨김** 처리됩니다.
- **다시 열기**: 트레이의 `CO` 아이콘을 **좌클릭**하거나, 우클릭 후 **[대시보드 열기]**를 선택합니다.

### ⑤ 윈도우 시작프로그램 설정 (`⚙️ 환경 설정 탭`)
- 좌측 **[⚙️ 환경 설정 & 시작프로그램]** 탭을 클릭합니다.
- **"윈도우 부팅 시 CodeOrbit 자동 실행 (Autostart)"** 체크박스를 켭니다.
- 이제 컴퓨터를 부팅할 때마다 백그라운드 트레이에서 자동으로 실행되어 IDE가 켜졌을 때 그래프 쿼리 준비를 마칩니다.
