# 🖥️ CodeOrbit 완벽 UI 매뉴얼 (Svelte 5 모던 컴포넌트 아키텍처)

CodeOrbit은 **Svelte 5 + Tailwind CSS 컴포넌트 기반 프론트엔드**와 **모듈화된 고성능 Rust 백엔드**로 구축된 코드 지식 그래프 데스크톱 매니저입니다.

---

## 📸 대시보드 구조 및 컴포넌트 안내

화면은 크게 **① 좌측 네비게이션 사이드바**, **② 상단 워크스페이스 콤보박스 제어 바**, **③ 중앙 실시간 4대 지표 카드**, **④ 하단 그래프 심볼 탐색기**로 모듈화되어 있습니다.

## 1. 상단 워크스페이스 콤보박스 제어 바 (`WorkspaceSelector.svelte`)

사용자가 긴 파일 경로를 매번 복사/붙여넣기할 필요 없이 **프로젝트를 드롭다운(콤보박스)으로 선택하고 관리**합니다.

| 컴포넌트 | 기능 및 사용 목적 |
| :--- | :--- |
| **📁 프로젝트 드롭다운 콤보박스** | 등록된 프로젝트 목록을 선택하여 즉시 분석 타겟을 전환합니다. (전환 시 백그라운드 지식 그래프 즉시 로드) |
| **[+ 추가] 버튼** | 새로운 프로젝트 폴더 경로를 입력하여 즐겨찾기 목록에 등록합니다. 로컬 설정(`~/.codeorbit/`)에 영속 저장됩니다. |
| **[✕] 삭제 버튼** | 더 이상 관리하지 않는 프로젝트를 드롭다운 목록에서 제거합니다. |
| **[⚡ 즉시 재인덱싱]** | 코드를 수정했을 때 클릭하면 변경된 소스코드를 즉시 다시 읽어 그래프를 최신 상태로 갱신합니다. |
| **[트레이로 숨김]** | 대시보드를 닫지 않고 윈도우 우측 하단 시스템 트레이로 숨깁니다. |

## 2. 실시간 4대 지표 카드 (`MetricsGrid.svelte`)

현재 선택된 프로젝트의 **규모와 지식 그래프 구축 상태**를 실시간으로 보여줍니다.

- **`INDEXED FILES`**: 현재 프로젝트 폴더 내의 전체 소스코드(Rust, C++, C#, TS, Py) 파일 수.
- **`KNOWLEDGE NODES`**: 파싱된 클래스(Class), 구조체(Struct), 함수(Function), 트레이트(Trait) 등의 심볼 수.
- **`RELATION EDGES`**: 함수 호출(`calls`), 모듈 임포트(`imports`), 인터페이스 구현(`implements`), 상속(`extends`) 간선 수.
- **`STORAGE ENGINE (ByteRAG 5T)`**: 순수 Rust 5-Tier KV & Graph 임베디드 데이터베이스에 초고속 영속 저장됨을 의미.

---

## 3. 하단 심볼 탐색기 (`SymbolExplorer.svelte`)

지식 그래프에 등록된 함수/구조체/클래스를 즉시 검색하고 위치를 파악합니다.
- 앱 실행 시 `main` 함수 등 핵심 진입점 심볼이 **자동으로 Warm-up 검색되어 즉시 렌더링**됩니다.
- 검색창에 함수명이나 구조체명을 입력하고 `Enter`를 누르면 즉시 필터링된 결과가 출력됩니다.

---

## 4. 좌측 네비게이션 & 상태 바 (`Sidebar.svelte`)

- **`⚡ 대시보드 개요`**: 실시간 지표 및 심볼 탐색기가 있는 메인 대시보드.
- **`🔌 MCP 도구 및 상태`**: Cursor / Antigravity AI가 연동하여 사용하는 13가지 MCP 도구 목록 확인.
- **`⚙️ 환경 설정`**: **"윈도우 부팅 시 자동 실행 (Autostart)"** 토글 스위치 (PC 부팅 시 백그라운드 트레이로 자동 상주).
- **`● MCP READY`**: 지식 그래프 엔진이 정상 준비되어 AI 요청을 처리할 수 있는 상태 표시.
